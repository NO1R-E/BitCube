#BitCube
This project is part of a Software Construction (01418211)

BitCube is a 100% Java desktop game designed to test quick mathematical thinking by connecting UI controls directly to core number conversion logic. Players defeat different types of enemies by converting binary bits on the fly to match target values in octal, decimal, and hexadecimal formats. Built as a collaborative team effort, this project focused heavily on mastering real-world software workflows—using Git and GitHub to manage branches and keep team code organized throughout development.
